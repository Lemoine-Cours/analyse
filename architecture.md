# Production des cours d’analyse

Le coordinateur et les rôles sont ceux du [dépôt atelier-slides](https://github.com/Lemoine-Cours/atelier-slides). Ce dépôt héberge les chapitres, leurs références, leurs sources et leurs livrables.

1. Inventorier les supports et préserver les originaux avec leurs empreintes.
2. Relever les notations et le niveau ; le TD de base sélectionne seulement les notions utiles.
3. Proposer un plan par définitions, théorèmes, hypothèses, exemples et méthodes ; faire approuver le plan avant les slides.
4. Rédiger sans preuves projetées ; vérifier l’ordre des prérequis et séparer les compléments.
5. Recalculer les exemples et vérifier les conditions des théorèmes.
6. Produire le Beamer avec le thème IMT commun ; compiler et inspecter chaque page rendue.
7. Préparer un ZIP autonome, le compiler et comparer son rendu au PDF publié.
8. Publier les sources, le PDF et les rapports dans le dossier du chapitre.

Rôles possibles : documentaliste, gardien des notations, pédagogue, rédacteur, vérificateur scientifique et relecteur visuel. Sans délégation autorisée, ces rôles sont exécutés successivement par le même assistant ; la relecture n’est pas indépendante. Une configuration prepare-only prépare les entrées sans appeler d’agents. Aucun profil propre à un chapitre n’est activé avant la réception de ses supports.
