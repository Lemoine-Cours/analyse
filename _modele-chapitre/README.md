# Modèle de chapitre d’analyse

Copier ce dossier vers le nom du chapitre. Ce squelette n’est pas un cours rédigé. Compléter le brief après lecture des supports ; préparer le plan, les notations et le storyboard avant les slides. Les références restent intactes.

Adapter `beamer/meta.tex`, puis remplacer `beamer/body.tex`. Compiler avec `./beamer/build.ps1` ou `bash beamer/build.sh`. Les sorties provisoires s’appellent `exports/chapitre.pdf` ; les renommer et adapter les scripts lors de la création du chapitre. Contrôler chaque page rendue avant de déclarer le PDF prêt.
